# stripped before sending.

# Keep current:

#   * the GATE PROBES section — whatever probe is live this round.

# NOTE: do NOT use `exit` in here. The driver wraps this in BEGIN/END markers and

#
# NOTE: do NOT rename the "--- NEW FOUND? ---" header or drop the "--- … ---"
# header style. daily_auto.sh greps "NEW FOUND" to detect that at least one
# cluster answered (no match = it aborts before the agent), and
# check_all_retry.sh slices sections on lines starting with "--- ". Rung labels
# INSIDE headers (n=32 -> n=33) are fine to change.
